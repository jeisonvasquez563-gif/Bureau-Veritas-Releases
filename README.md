# Bureau Veritas — Releases

Este repositorio distribuye **únicamente los instaladores compilados** (`.exe`) de
la aplicación Bureau Veritas (BV2026). No contiene código fuente.

El código fuente vive en un repositorio privado aparte. Este repo existe para que
la función de auto-actualización de la app pueda descargar los instaladores sin
necesitar credenciales de GitHub (el repo de código es privado y bloquea
descargas anónimas de sus releases).
